How to read the dish
Each dot is one agent session (Claude Code, Claude Cowork, Kiro, Antigravity, Gemini, Codex). The dish replays from , then keeps growing live when served. Colony titles follow what each colony has been about in the last few days.
Size = output tokens so farThe dot grows as the session produces tokens (log scale):
Ring = working nowProduced output in the last 10 minutes.
Faded = idleThe longer since its last message, the fainter: an hour, a day, a week.
Black dots = sub-agentsHelpers it spawned (cell division).
Orange line = hand-offA later session read or edited a file this one wrote. The ring marks the receiver.
Fixed placesA colony appears at its own spot when its first session starts and grows around it. It never moves. How recent a cell is shows in how bright it is: full while in use, fading with each hour, day and week idle. Unthemed sessions form the outer band.
Colony = themeSessions whose prompts and files share a recurring phrase form a colony, named by that phrase. The rest are unthemed (grey-blue).
Floor glow = heat mapEach cell tints the dish around it in its colour. Glows blend where colonies meet and run stronger where more is happening.
